# M2 Handoff — Visual redesign + naming fixes

## What was done

### 2.1 Design tokens (`src/ui/tokens.ts`)
Created a single source of truth for every color in the app. All hex values live here — none in component files. Key exports:
- `PALETTE` — full colour table (day identity, muscle badges, prescription semantics, surfaces)
- `dayAccent(day)` — returns the day's accent hex (`push → #3264d8`, etc.)
- `blockColors(label)` — returns `{ border, pillBg, pillText }` for Power/Strength (blue) vs Hypertrophy (green) vs neutral

CSS custom properties for static Tailwind-compatible colours added to `src/index.css` via `@theme`.

### 2.2 Naming fixes
All `SEED_BLOCKS` labels changed to the owner's vocabulary (Power / Strength / Hypertrophy / Bodyweight / Work / Burnout). Removed "Main sets", "Back-off", "AMRAP sets", "Strength set", "Hypertrophy sets", "Burnout set".

`SEED_VERSION` bumped to 3 — the migration runs once per device, updating every block label in-place while preserving all `setLog` references.

### 2.3 Components rebuilt

**`src/ui/Stepper.tsx`** — buttons now 48×48 px; number input uses `font-variant-numeric: tabular-nums`.

**`src/features/workout/RestTimer.tsx`** — `navigator.vibrate` removed, replaced with a three-note WebAudio ascending tone (C5 → E5 → G5). Timer bar coloured by day accent. Respects `prefers-reduced-motion`.

**`src/ui/Nav.tsx`** — accepts `sessionDay?: Day | null`; active tab renders in the day accent colour instead of hardcoded blue.

**`src/App.tsx`** — tracks `sessionDay` state, passes to Nav. WorkoutPage reports the session day via `onDayReady` callback.

**`src/features/workout/DayPicker.tsx`** — each day button uses its day accent colour.

**`src/features/workout/ExerciseCard.tsx`** — full §5 anatomy:
1. Collapsed row: thumbnail, index + name, first block prescription, last session top set
2. Expanded header band in day colour with "N/M sets" counter
3. Illustration on white plate (`#ffffff`)
4. Prescription blocks via BlockLogger
5. Muscle badges (Main / Syn / Stab) with exact PDF colours
6. Watch form + Form cues as equal secondary buttons; form text collapsed by default
7. Note callout in amber

**`src/features/workout/BlockLogger.tsx`** — full redesign:
- 3 px left border in semantic colour (blue Power/Strength, green Hypertrophy, neutral else)
- Label pill + prescription on one line
- Previous session sets shown in mono/dim
- Plate calculator display below weight stepper
- Log button label: "Log set 4 · 185 lb × 5" (tabular figures)
- Callbacks to ExerciseCard for progress tracking

**`src/features/workout/ExerciseList.tsx`** — passes `index` to ExerciseCard.

**`src/features/workout/WorkoutPage.tsx`** — day-coloured header; "Start push day" button in day colour; day picker uses day colours.

### 2.4 Plate calculator (`src/domain/plates.ts`)
`calculatePlates(targetLb, inventory, barLb)` — greedy from largest plate. Returns `{ perSide, achievable, nearestBelow }`. If the weight isn't exactly loadable, shows the nearest achievable and which plates to load.

Default home inventory: 45/35/25/10/5/2.5 lb in pairs.

**Settings page** (`src/features/settings/SettingsPage.tsx`) — added "Plate inventory" section: per-plate pair count editable with +/− buttons, persisted to IndexedDB `meta` table. Reset to defaults button.

## Seed migration
`SEED_VERSION` is now 3. Any device running v1 or v2 will automatically update block labels on next load. No data is lost — setLogs reference block IDs which are unchanged.
