# Build & Deploy Specification

## Build

```
npm ci
npm run build   # tsc -b && vite build
```

Output goes to `dist/`. The build must pass TypeScript compilation before Vite runs.

## Environment
- Node 20
- No environment variables required — all data is stored client-side in IndexedDB

## Deployment target
GitHub Pages via `actions/deploy-pages@v4`.

- URL: `https://vbanga2.github.io/ppl-tracker/`
- Branch: `main` triggers the workflow automatically
- Artifact: entire `dist/` directory uploaded with `actions/upload-pages-artifact@v3`

## Required workflow permissions
```yaml
permissions:
  contents: read
  pages: write
  id-token: write   # required by actions/deploy-pages
```

## Key invariants
| Item | Required value |
|------|---------------|
| `vite.config.ts` `base` | `/ppl-tracker/` |
| PWA `start_url` | `/ppl-tracker/` |
| PWA `scope` | `/ppl-tracker/` |
| Service worker `navigateFallback` | `/ppl-tracker/index.html` |

## PWA
The service worker is generated by Workbox (via `vite-plugin-pwa`). Caches all JS/CSS/HTML/images plus a `NetworkFirst` strategy for `world.openfoodfacts.org` API calls.

## Local preview
```
npm run build
npm run preview   # serves dist/ at localhost:4173/ppl-tracker/
```
